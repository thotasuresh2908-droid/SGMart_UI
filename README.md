# SGMart web (React)

The shop and admin screens for SGMart. See `../docs/FRONTEND.md` for the full guide.

```bash
npm install
npm run dev        # http://localhost:5173 (backend must run on :8080)
npm test           # unit and component tests
npm run build      # production build in dist/
```

Backend: https://sgmart-backend.onrender.com (reached through the rewrite rules in vercel.json / render.yaml)
